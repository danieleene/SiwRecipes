🥘SiwRecipes🍝
Benvenuto in SiwRecipes, un'applicazione per la gestione di ricette e autori, con funzionalità diverse in base al ruolo dell'utente.


*Casi d'Uso📃*

Utente generico(non autenticato)👤

🔍Consultazione delle ricette(dettaglio di una ricetta+recensioni)

🔍Visualizzazione dell'autore di una ricetta(pagina dell'autore e le ricette da lui pubblicate)

🔍Ricerca delle ricette per Categoria


Utente registrato(USER)✅


➕Inserimento di una ricetta

➕Inserimento di una recensione

❌Cancellazione delle proprie recensioni

❌Cancellazione delle proprie ricette

✏️Modifica delle proprie ricette


Utente registrato(ADMIN)🔐


➕Inserimento di una nuova ricetta

✏️Aggiornamento di una ricetta esistente

➕Inserimento di una recensione

❌Cancellazione di recensioni

❌Cancellazione di ricette
